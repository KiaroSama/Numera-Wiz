# Revision 6: media workflow completeness review

**Date:** 2026-10-22. **Reviewed baseline:** revision 5.0. **Status:** source/document review; no application build, FFmpeg job, media benchmark or GPU run.

The revision 5 media chapter and FFmWiz annex already preserve substantial functionality. This review does not repeat the recent color/light fixes or relabel every missing implementation as a new defect. It identifies decisions that the implementation agent would still have to invent while connecting the existing requirements into working media journeys. The selected closure text is in `media-workflows.md`; root integration must preserve one authoritative contract.

## Findings and closure

| M6-03 | P1 | FFmWiz F12 and **Join/concat** preserve later-only tracks but leave logical track correspondence and exact segment extent to the implementation. | M6-04 | P1 | `command-domain-contract-final.md` / **CD02** and `mandate-media.md` / **Audio, loudness and live control** list routing, sends and automation but omit the donor's observable strip order and insert compensation. Compile an effective latency ledger and compensation per bus. Creative delay is separate from algorithmic alignment delay. | WP08; M6-J05, M6-J06. |
| M6-05 | P1 | The same audio section and descriptor **Automation** field do not select an offline automation accuracy contract. FFmpeg `volume` with `eval=frame` evaluates once per audio frame, which cannot substantiate sample-accurate gain/mute/pan automation or frame-size-independent output. | Gain/mute/pan lanes use qualified per-sample FFmpeg expressions/envelope routes; other parameters advertise their actual qualified update grid or immutable-graph limit. Live acknowledgment remains separate from offline rendering. Do not inherit the donor's private 64-sample DSP implementation. | WP08; M6-J06. |
| M6-06 | P1 | **Stateful effects**, **Reverse/boomerang**, cache keys and resource budgets describe bounds but do not choose the graph-partition/materialization strategy. One graph opening every timeline source breaks the lightweight requirement; arbitrary chunks reset temporal filters and seeded generators. | Bounded active dependency closures and state-aware partitions. Use native continuous stages or explicit lossless materialization for stateful islands. No FFmpeg-private state serialization is assumed; shared seed alone does not establish chunk/seek equivalence. Preserve continuous processing where exact restart is unavailable. | WP05/WP07/WP08; M6-J07, M6-J08. |
| M6-07 | P1 | **Probe, capabilities and stream preservation** represents unknown/incomplete duration but does not select the next action for operations needing complete duration/index information, such as remove-range complements, reverse, percent screenshots or copy eligibility. | Classify metadata probe, bounded timestamp/index scan and full scan/materialization separately. Required unknown facts become explicit analysis stages or typed preflight failures. Reaching a supplied input bound is not silently treated as EOF or a successful truncated export. | WP05/WP07; M6-J09. |
| M6-08 | P1 | FFmWiz F03/F10/F12 and **One authoritative model** require subtitle/chapter retiming without selecting how cues crossing cuts, reverse spans, repeated occurrences, freezes and overlaps are mapped. Applying one global speed multiplier or retaining original subtitle packets is insufficient. | A piecewise event mapper driven by the same `TimeMap`, with clipped/split cue intervals, repeated occurrence IDs, explicit hold/reverse rules and ownership of overlapping language tracks. Burn after mapping unless source-locked graphic semantics were explicitly selected. | WP05/WP07/WP08; M6-J10. |
| M6-09 | P2 | **Validate outputs independently after process success** lists many properties without selecting verification depth, expected evidence or handling legitimate bitstream reframing. This can become either a superficial probe or an unnecessary second full decode for every ordinary task. | Verification profiles with mandatory structure/identity checks, workflow-specific assertions and explicit sampled/full-decode scope. CI qualifies all fixtures through independent decoded/packet oracles. Exact-copy evidence distinguishes byte copy, packet preservation and compatible remux with declared bitstream conversion. | WP07; M6-J11, M6-J12. |

These findings are specification gaps, with M6-04 additionally grounded in concrete donor routing semantics. They are not observed application failures. The new chapter selects behavior without claiming that an unexecuted graph is qualified.
