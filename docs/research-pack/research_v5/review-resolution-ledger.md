# Revision 5 correction ledger

Revision 5.0. This ledger distinguishes corrected specification defects from actual runtime qualification. **Applied** means the authoritative English mandate and relevant current inventories contain the selected correction. It does not mean a Numera application, FFmpeg recipe, browser or GPU run has passed.

The bounded requirement, execution and media reviews are preserved in this directory. Their line numbers and `research_v4` locations identify the prior reviewed text; obsolete normative chapters are not packaged as additional instructions. Use the revised main mandate and `research_v5` mappings for implementation. Historical manual-reading evidence remains in `research_v4` with its original hashes and provenance.

## Scope retained

The revision retains the full FFmWiz behavioral annex, all 303 FilmCraft and 307 EffectCraft source records, the 296-proposal cross-donor reconciliation, all 942 source-command records, the shared Rust GUI and local FFmpeg engine, portable packaging, CI-built ordinary tests and owner-local GPU qualification. Source inventory counts are not a count of working features.

Previous consequential corrections remain binding: NUT nonnegative transport origin and restricted parser; correct metric input roles and frame correspondence; literal text handling and typography dependencies; varblur guide/radius/resource limits; Cairo layer precision and alpha; explicit command/source semantics; accepted-job grants; publication fences; finite replay retention and actual output verification.

## Evidence boundaries

Document checks verify generation, source-ID preservation, corrected field consistency, references, fences and package hashes. They do not validate the FFmpeg output of any proposed recipe. Runtime, performance, security, browser and protocol assertions above must be implemented and run through the mandate's prescribed CI gates. GPU qualification runs on the owner's machine using the matching CI-built bundle. No local application build or media/GPU test was performed for this document revision.
