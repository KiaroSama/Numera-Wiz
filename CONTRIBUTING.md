# Contributing

Read AGENTS.md, the constitution, the current specification and affected mandate
sections. Use the installed Spec Kit chain; retain concrete tasks and acceptance
assertions. Submit changes for review on the implementation branch. Build and
ordinary validation run in GitHub Actions; owner GPU testing uses only CI artifacts.
Never merge/close the owner's PRs or issues, enable auto-merge, or invent evidence.
Preserve third-party license notices when translating/adapting source behavior.
