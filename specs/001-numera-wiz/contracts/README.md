# Contracts

`nw-domain::commands` and `nw-domain::mux` are authoritative typed contracts.
Generate JSON schemas with the Rust xtask. Each command has one ID, version,
state class and parameter schema. CLI/application HTTP/MCP/UI use those same
parameters. Development-only availability is explicit until five-surface evidence.
The complete target envelope, bootstrap, profile and object policies remain in
mandate Sections 4-5. Current missing contracts are tasks, not silent defaults.
