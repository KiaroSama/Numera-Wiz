# Validation quickstart

Use the Actions run associated with the implementation branch. Download its named
artifacts; check the commit/component identities before executing them. This is a
development branch with no complete portable release yet. Do not install a compiler
or run ordinary source builds locally. Owner GPU instructions will be enabled only
when the matching CI-built qualification bundle exists.

The hosted domain suite checks exact VFR mapping, index 0, original-language tag
precedence, independent attachments, explicit no-match, strict field placement and
structural request digests. The media/package/interface suites close subsequent gates.
